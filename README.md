# واجهة التداول للجوال

المصدر الكامل لواجهة تداول عربية متجاوبة مبنية باستخدام React. يعرض التطبيق أسعارًا من BiQuote عند توفرها، ويحتوي على الرسوم البيانية واختيار الأصول وسجل الصفقات والمحفظة والمكافآت.

**هذا التطبيق محاكاة محلية، وليس منصة تداول مالي حقيقية.** الإيداع والسحب والموافقة والأرصدة والصفقات وواجهات الحساب لا تتصل بخادم حسابات أو نظام دفع.

## التثبيت والتشغيل

تحتاج إلى Node.js 24 أو أحدث وnpm، وإلى Python 3 للخادم المحلي واختبار المتصفح الاختياري.

```sh
npm ci
npm run build
npm start
```

افتح `http://127.0.0.1:8786`. يشغّل `npm start` خادم ملفات محليًا على جهازك فقط. يمكن تقديم مجلد `public/` من أي خادم ملفات ثابتة بعد البناء؛ لا حاجة إلى مفاتيح API لتجميع التطبيق.

## الاختبارات

```sh
npm test
```

يشغّل اختبارات المحفظة في الذاكرة، ومنع تجاوز الرصيد وتكرار المعاملات، وتحويل الأسعار والتحقق من صلاحيتها. لا تقرأ هذه الاختبارات بيانات متصفحك ولا تتطلب اتصالًا بخدمة الأسعار. بعض اختبارات الأسعار تتحقق من بنية المصدر، لذلك يلزم تحديثها عند إعادة هيكلة وحداته.

لاختبار واجهة اختيار الأصول اختياريًا، اترك الخادم المحلي يعمل في نافذة منفصلة:

```sh
python3 -m pip install -r tests/requirements.txt
python3 -m playwright install chromium
npm run test:e2e
```

يمكن تحديد عنوان محلي مختلف باستخدام `python3 tests/test-asset-picker.py http://127.0.0.1:8786/`. يستخدم الاختبار جلسة متصفح جديدة، ويضع نتائجه في مجلد نظام مؤقت. لتحديد مكان النتائج عيّن `TEST_ARTIFACT_DIR`؛ ولا ترفع هذه النتائج إلى المستودع. لاستخدام Chromium مثبت مسبقًا عيّن `CHROMIUM_PATH` إلى مساره. اختبار الواجهة ليس اختبارًا لتوافر أو دقة مزود الأسعار الخارجي.

## ترتيب الملفات

- `src/`: مكونات React، التنسيقات، جلب الأسعار، ومنطق المحاكاة.
- `public/`: صفحة الدخول والأصول والصور والشعارات وملفات JavaScript/CSS المبنية، جاهزة للتقديم الثابت.
- `build.mjs`: تجميع React بواسطة esbuild وتوليد تنسيقات Tailwind وتحديث بصمة ملفات الواجهة.
- `package.json` و`package-lock.json`: أوامر المشروع والاعتمادات المثبتة بالإصدارات المقفلة.
- `tests/`: اختبارات المنطق والأسعار واختبار الواجهة الاختياري.
- `P`: الملف الأصلي للمستودع، محفوظ دون تعديل.

## البيانات والأمان

يتصل المتصفح مباشرة بـ `https://biquote.io/api` و`https://biquote.io/hubs/tick`. يعتمد توافر الأسعار على اتصال الشبكة ودعم المزود وسياسة CORS. لا توجد خدمة خلفية خاصة بالحسابات ضمن هذا المصدر.

يستخدم التطبيق `localStorage` لتفضيلات المستخدم وبيانات المحاكاة على جهازه. المنطق الذي ينشئ هذه البيانات جزء مطلوب من التطبيق؛ أما بيانات الجلسات الفعلية وصادرات المتصفح فليست مضمّنة في المستودع. رمز دخول لوحة الموافقة الموجود في الواجهة رمز عرض محلي علني، وليس سرًا أو مصادقة حقيقية، ولا يجوز استخدامه لحماية خدمة فعلية. حقول كلمات المرور واجهة عرض ولا تنشئ نظام حسابات.

لا تضع أسرارًا داخل المصدر أو ملفات `public/`: كل ما يصل إلى المتصفح قابل للقراءة. الملفات المحلية مثل `.env` و`.dev.vars` والمفاتيح وسجلات Wrangler وحالة الحساب والنشر وروابط المطالبة غير مرفوعة. تمنع `.gitignore` رفع هذه الفئات، بالإضافة إلى `node_modules/` والذاكرات المؤقتة ولقطات جلسات الاختبار والنسخ الاحتياطية المحلية.

لا يتضمن المستودع إعداد حساب نشر مؤقت أو أمرًا لإعادة النشر. رفع المصدر لا يغير الموقع المنشور.
